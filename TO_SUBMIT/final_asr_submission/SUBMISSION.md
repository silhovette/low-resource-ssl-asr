# Submission Contents

Submit the following:

- `report/build/main.pdf`: final ICASSP-style project report.
- `report/main.tex`, `report/refs.bib`, `report/spconf.sty`, `report/IEEEbib.bst`: editable report source.
- `src/`, `scripts/`, `configs/`: reproducible ASR implementation.
- `results/`: summary CSV, LaTeX table, and error-analysis examples.
- `outputs/*_hf_cuda/metrics.json` and `outputs/*_hf_cuda/test_predictions.csv`: measured 1h CUDA outputs.
- `README.md` and `REPRODUCIBILITY.md`: setup and run instructions.

Do not submit raw LibriSpeech audio unless the instructor explicitly asks for it.
